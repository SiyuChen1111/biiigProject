# Data Sources Guide

## Primary EEG Source: Kosciessa et al. (2021)

| Field | Value |
|-------|-------|
| Citation | Kosciessa et al. (2021). Thalamocortical excitability modulation guides human perception under uncertainty. *Nature Communications*, 12, 2430. |
| DOI | https://doi.org/10.1038/s41467-021-22511-7 |
| Data type | Response-locked single-trial EEG epochs |
| Channels | CP1, CP2, CPz |
| Alignment | Response-locked (0 ms = button press) |
| N trials | 7297 across 41 participants |
| N timepoints | 308 per trial |
| Raw path | Data/InputData/raw/Kosciessa_et_al_2021/temp_data/resp_locked_erp.mat |
| MATLAB variable | resp_locked_erp — shape (N, 3, T) → transposed to (N, T, 3) |

## Processed Dataset: Data/ProcessedData/

| File | Shape | Description |
|------|-------|-------------|
| eeg_cpp_trials.npy | (7297, 308, 3) float32 | z-scored response-locked EEG |
| times_ms.npy | (308,) float32 | Time axis in ms; 0 = response |
| metadata.csv | (7297, K) | Per-trial behavioural metadata |
| channel_names.txt | text | CP1, CP2, CPz |
| preprocessing_notes.md | text | Filter/reference/artefact notes |
| validation_report.json | JSON | DataContract pass/fail report |

## Intermediate Data: Data/IntermediateData/latents_full/

| File | Shape | Description |
|------|-------|-------------|
| latents_full.npz → latents | (7297, 308, 32) float32 | GRU hidden states |
| latents_full.npz → times_ms | (308,) float32 | Time axis |

Generated by: Scripts/s2_training/train.py → export_full_latents_from_checkpoint()

## Notes
- Raw MATLAB files are **not tracked in git** (file size).
- All analyses are reproducible from Data/ProcessedData/ and Data/IntermediateData/.
- To re-run from scratch, place raw files at the paths above and run Step 0 of Scripts/master_pipeline.ipynb.
